# 약국 디지털 사이니지 광고매체 사업성 분석

전국 약국에 디스플레이를 설치해 오프라인 광고매체 네트워크를 구축하고 광고를 유치해
수익을 내는 사업의 시장성·수익성 진단.

## 결론 요약

**조건부 진입** — 매체 인벤토리(약국 2.5만개·유동수요·경쟁 공백)의 시장성은 확인되나,
5년 단독 손익 기준 NPV는 대부분의 현실 시나리오에서 마이너스. 성숙 유닛 이코노믹스는
흑자(회수 1.6년)이므로 "규모 도달 전 J커브 자금(약 76억+)을 버티는가"가 관건인
전형적 규모형 매체 플랫폼 구조.

핵심 변수는 **스크린당 월 광고매출**. 5년 NPV가 0이 되려면 성숙기 약 24만원 필요
(기본 가정 12만원의 2배) → 프리미엄 단가 확보 여부가 생사를 가름.

## 파일

| 파일 | 내용 |
|---|---|
| `report.html` | 종합 사업성 리포트 (시장·경쟁·규제·수익성·권고, 인터랙티브 차트) |
| `model.py` | 5년 유닛 이코노믹스 모델 (시나리오 3종·NPV·손익분기) |
| `sensitivity.py` | 토네이도 민감도 + 2-way NPV 표 + 손익분기 탐색 |

## 실행

```bash
pip install numpy scipy matplotlib pandas
python3 model.py
python3 sensitivity.py
```

## 방법론

- **모델링**: creating-financial-models 스킬 방법론 (시나리오·민감도·손익분기)

## 주요 가정 (기본 시나리오)

스크린당 설치비 100만원, 월운영비 2.5만원, 성숙 월광고매출 12만원, 약국배분 20%,
할인율 15%. 설치·DOOH·규제 수치는 공개 리서치 기반, 스크린당 광고단가·기존 사업자
규모는 **미확증 추정**으로 파일럿 검증 대상.

## 다음 단계 권고

1. **파일럿**(50~100개 약국, 3~6개월): 스크린당 실제 월 광고매출·채움율 실측
2. **광고주 LOI**: 건기식·제약사 대상 단가표 검증
3. **Go/No-Go 게이트**: 월매출 ≥15만원 & 채움율 40%+ 달성 시에만 확장
4. **확장**: 단계적 투자 유치로 3,000개+ 네트워크
