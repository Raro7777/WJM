# 약국 디지털 사이니지 광고매체 사업성 분석

전국 약국에 디스플레이를 설치해 오프라인 광고매체 네트워크를 구축하고 광고를 유치해
수익을 내는 사업의 시장성·수익성 진단.

## 결론 요약

두 가지 수익모델을 비교 분석함.

### 모델 B · 자체 성과광고 (권장) ★
운영사가 온라인 성과광고 역량을 보유 → 스크린에 **자체 광고(인입 3만원/접수전화
15만원)를 직접 태움**. 매체 마진이 아니라 리드 가치 전액을 회수하고 첫날부터 100%
가동(채움율 리스크 소멸).

**적극 추진** — 기본 시나리오 5년 NPV **+169억**, 스크린 회수 **약 3개월**, 필요 투자금
**5억**, 손익분기 **451개 약국**. NPV 손익분기는 스크린당 월 2.5리드(방문객 0.05% 응답)로
매우 낮음. 병목이 수익화가 아니라 **설치 전개속도(실행력)**로 이동.

### 모델 A · 외부 DOOH 슬롯 판매 (비교 기준)
외부 광고주에게 슬롯 판매. 5년 NPV −50억, 회수 1.6년, 손익분기 3,378개. 광고단가·채움율
리스크로 한계사업. **모델 B의 대조군으로만 유지.**

## 주요 가정 (모델 B 기본 시나리오)

인입 3만원·접수전화 15만원(제시값), 스크린당 월 7리드+1.5전화(성숙), 설치비 100만원,
월운영비 2.5만원, 약국배분 20%, 할인율 15%. 리드·전화 발생 수는 **미확증 추정**으로
파일럿 검증 대상. 약국 수·DOOH·규제 수치는 공개 리서치 기반.

## 다음 단계 권고 (모델 B)

1. **파일럿**(50~100개 약국, 2~3개월): 스크린당 실제 월 리드·전화 수 실측 (손익분기 2.5리드 초과 여부)
2. **버티컬 최적화**: 건강·보험·상조·요양 중 접수전화(15만) 최다 소재 확정
3. **Go/Big-Go 게이트**: 스크린당 월 리드 ≥4건이면 공격적 확장(회수현금 재투자)
4. **스케일**: 설치·계약 표준화에 집중 투자 → 3,000개+ 빠르게 도달
